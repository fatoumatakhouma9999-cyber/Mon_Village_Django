# Mon Village Django - Bandandar

Projet Django de presentation du village Bandandar.

## C'est quoi ?
Site web pour presenter le village Bandandar : son histoire, ses habitants, ses activites et ses photos.

## Fonctionnalites
- Page d'accueil du village
- Presentation de l'histoire
- Galerie photos
- Page contact

## Comment lancer le projet
1. python -m venv venv
2. venv\Scripts\activate
3. pip install -r requirements.txt
4. python manage.py runserver
5. Ouvrir http://127.0.0.1:8000/

## Technologies
Python, Django, HTML, CSS
